# Gender Gaps in Employment: A Comparative Analysis of Foreign-Born and Overall Working-Age Populations in Six European Countries, 2016–2025

## Project Overview

This independent quantitative research project examines gender differences in employment and unemployment across six European countries: Belgium, Germany, Spain, the Netherlands, Finland and Sweden.

Using secondary statistical data from Eurostat, the research compares labour-market outcomes among foreign-born and overall working-age populations aged 20–64.

## Research Objectives

1. Examine gender differences in employment rates.
2. Compare unemployment outcomes between women and men.
3. Investigate differences between foreign-born and overall working-age populations.
4. Explore cross-national patterns over the 2016–2025 period.

## Methodology

The project uses quantitative secondary-data analysis and a comparative research design. Data are organised by country, year, population group and sex. Descriptive statistical comparisons and gender-gap indicators are used to examine labour-market outcomes.

## Data Source

Eurostat – European statistical data on employment and unemployment.

## Tools

- Microsoft Excel
- Spreadsheet-based data analysis
- Comparative statistical analysis
- Data visualisation and dashboard development
